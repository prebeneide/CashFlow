# CashFlow

Moderne regnskapssystem for små og mellomstore bedrifter.

## Teknologi

- Flutter (iOS, Android, Web)
- Material Design 3
- Easy Localization (Engelsk/Norsk)
- Provider (State Management)

## Getting Started

```bash
flutter pub get
flutter run -d chrome
```

## Features

- Moderne tema-system (Light/Dark mode)
- Flerspråkstøtte (Engelsk/Norsk)
- Responsiv design
